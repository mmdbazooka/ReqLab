# ReqLab

ابزار محلی تست API: مدیریت کالکشن، محیط، هدر و بدنه، مشاهده JSON پاسخ و بازپخش تاریخچه.

با Next.js، TypeScript و Tailwind CSS ساخته شده است. رابط فارسی/انگلیسی، پشتیبانی RTL، فونت وزیرمتن، تم روشن و تاریک و طراحی ریسپانسیو دارد.

## اجرا

Node.js نسخه ۲۴ لازم است. به دیتابیس یا کلید API نیازی نیست.

```bash
npm ci
npm run dev -- --port 3001
```

برای production:

```bash
npm run build
npm start
```

## صفحات

نمای کلی، محیط درخواست، کالکشن‌ها، محیط‌ها، تاریخچه و تنظیمات؛ به‌علاوه لندینگ محصول.

## ذخیره و پشتیبان

داده‌ها در localStorage همین مرورگر و آدرس سایت ذخیره می‌شوند. پاک کردن داده مرورگر ممکن است آن‌ها را حذف کند. از تنظیمات خروجی JSON بگیر؛ وارد کردن پشتیبان، پس از تأیید، داده فعلی را جایگزین می‌کند. زبان و تم مستقل از پشتیبان ذخیره می‌شوند.

درخواست مستقیماً از مرورگر ارسال می‌شود و API باید CORS را مجاز کند. کوکی ارسال نمی‌شود. ۱۰ اجرای آخر و تا ۱۰۰ کیلوبایت از هر پاسخ نگهداری می‌شود. متغیرها و رمزها در حافظه محلی و خروجی پشتیبان به شکل متن ساده هستند؛ فایل دارای رمز را منتشر نکن.
